# Operator Trainer (old versions)

**This repository has moved to [wingamingpl/operator-trainer](https://github.com/wingamingpl/operator-trainer).**

Operator Trainer 1.1.5 and newer read all their online settings from the new repository: the version check, official build list, announcements, news and settings.

## Why this repository still exists

Operator Trainer **1.0.0, 1.0.5 and 1.1.0** still check this repository to see whether they are supported. It only keeps the files those versions need:

| File | What it does |
|---|---|
| `min-version` | Tells old versions that they need to update. |
| `allowed-hashes` | Fingerprints of the official old builds. |
| `update-reason` | The reason shown to 1.1.0 when it asks you to update. |

These versions are no longer supported. If the menu says **"Update required"**, download the latest version of Operator Trainer from **[Nexus Mods](https://www.nexusmods.com/operator/mods/263)** and replace `OperatorTrainer.dll`. Your settings are kept.

## Where everything is now

| What | Where |
|---|---|
| The mod | [Nexus Mods](https://www.nexusmods.com/operator/mods/263) (the only official download) |
| Online settings for 1.1.5 and newer | [wingamingpl/operator-trainer](https://github.com/wingamingpl/operator-trainer) |
| Bug reports | The **Bugs** tab on the Nexus Mods page |
